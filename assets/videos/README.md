# Videos Folder

Coloca tu video de fondo aquí con el nombre `background.mp4`.

El video se reproducirá automáticamente en bucle como fondo de las pantallas de:
- Login
- Registro
- ¿Olvidaste tu contraseña?

## Formatos recomendados:
- MP4 (H.264)
- WebM
- MOV

## Especificaciones sugeridas:
- Resolución: 1920x1080 o 1280x720
- Duración: 10-30 segundos (se repetirá en bucle)
- Tamaño: Menos de 10MB para mejor rendimiento

## Si no hay video:
La app usará un gradiente de fondo como alternativa.

## Ejemplo de nombre de archivo:
`background.mp4`
